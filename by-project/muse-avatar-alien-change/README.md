# muse-avatar-alien-change

Assets from the Muse avatar change: the original fluffy avatar, body options,
cap and tee iterations, the final alien avatar, and the orb-spinning change
animation.

## Files

- `fluffy-original.jpg` — original fluffy avatar reference
- `body-option-1.png` … `body-option-4.png` — body options
- `iter-1-cap-backwards.png` … `iter-7-cap-tee-v3.png` — cap/tee iterations
- `alien-final.png` — final alien avatar
- `fluffy-orb-spinning-hd.mp4` — orb-spinning change animation (HD upscale)
