# muse-avatar-alien-change

Assets from the Muse avatar change (October 2026): the original fluffy avatar,
body options, cap and tee iterations, the final alien avatar, fluffy system
clips, and the orb-spinning change animation.

## Images

- `fluffy-original.jpg` — original fluffy avatar reference
- `original-avatar.png` — avatar before the change
- `body-option-1.png` … `body-option-4.png` — body options
- `iter-1-cap-backwards.png` — iteration 1: cap backwards
- `iter-2-cap-tee-outline-heart.png` — iteration 2: cap + tee, outline heart
- `iter-3-cap-tee-red-heart.png` — iteration 3: cap + tee, red heart
- `iter-4-cap-sideways.png` — iteration 4: cap sideways
- `iter-5-cap-sideways-tee.png` — iteration 5: cap sideways + tee
- `iter-6-cap-tee-v2.png` — iteration 6: cap + tee v2
- `iter-7-cap-tee-v3.png` — iteration 7: cap + tee v3
- `alien-final.png` — final alien avatar (sideways cap, white tee, red heart)
